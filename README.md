# Hi 👋

I'm **Marc Pàmpols**, CTO at [Rodi Motor Services](https://www.rodi.es/) and [REDD Parts](https://www.redd.es/), based in Lleida, Spain.

I have spent close to twenty years building web platforms, ecommerce and integrations. I started out writing code and today I lead the group's digital teams: an automotive business with more than 190 workshops across Spain, Andorra and Portugal.

### What I'm working on

- **Architecture and platform.** I design systems end to end.
- **Integrations.** I built the API manager every integration in the group now runs through. REST and SOAP APIs on top of ERP, with queues, traceability and metrics.
- **Ecommerce and B2B.** Shops and trade portals with tens of thousands of parts and real-time stock.
- **AI where it saves work.** Document recognition, call transcription and classification, catalogue extraction. No demos.
- **Team.** Roadmap, priorities agreed with the business, growth for each person, and hiring for technical roles.
